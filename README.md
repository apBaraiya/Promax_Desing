📌 About The Project

This project is a fully responsive animated website designed with a clean and modern user interface.

The website uses GSAP (GreenSock Animation Platform) to create smooth animations and interactive visual effects throughout the website.

It is developed using standard frontend technologies without any frontend framework, making it lightweight, easy to understand and easy to maintain.

✨ Key Features

📱 Fully responsive design

💻 Desktop, tablet and mobile support

🎨 Modern and clean UI

⚡ Smooth GSAP animations

🔄 Interactive navigation

📐 Bootstrap responsive grid system

🎭 CSS hover and transition effects

🚀 Optimized frontend structure

🛠️ Technologies Used: HTML5, CSS3, JavaScript, Bootstrap, GSAP

🎯 Project Goals

The main goals of this project were:

Build a modern animated website using vanilla frontend technologies.

Create a responsive layout using Bootstrap.

Implement smooth and professional animations using GSAP.

Practice advanced CSS and JavaScript interactions.

Create reusable and maintainable frontend code.

Provide a consistent experience across desktop and mobile devices.

🌐 Browser Compatibility

The website is designed to work with modern browsers such as:

Google Chrome, Microsoft Edge, Mozilla Firefox, Safari
